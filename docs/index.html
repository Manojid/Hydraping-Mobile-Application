What it does

Not a generic hydration timer — every feature is built to make reminders something you actually respond to.

⚡

Animated mascot companions

Pikachu, Jerry, or Whiskers react across 4 mood states — thirsty, happy, celebrating, sleeping — based on your real progress.

🌊

Live background animations

Liquid Wave, Rippling Pulse, or Cyber Orb — fluid real-time animation behind your mascot on the dashboard.

🔔

Adaptive smart reminders

A pacing engine recalculates reminder intervals and catch-up volumes from your intake velocity and active hours — not a fixed timer.

📲

Rich heads-up notifications

Full progress, character dialogue, and one-tap Drink 250 ml / Log / Snooze — no expanding required.

🔊

Procedural sound design

Zero-latency 16-bit PCM audio synthesized on-device via AudioTrack — Crystal Chime, Water Drop, Radar Ping, Bubble Pop.

☀️

Real-time weather boosts

Pulls live temperature from the keyless Open-Meteo API and bumps your target by up to 500 ml on extreme heat days.

📊

Trends & personal records

On-track pacing %, average sip volume, active streaks, peak drinking hours, and all-time best-day / longest-streak milestones.

🔒

100% offline-first

Everything lives on-device in Room SQLite. No account, no cloud sync — with JSON/CSV backup & restore whenever you want it.

Architecture

Clean architecture with MVI/MVVM, entirely offline, entirely Compose.

UI layer — 100% Jetpack Compose with Material 3 and a custom Cyber-Dark design system. State managed via Kotlin StateFlow / SharedFlow.

Domain layer — the Adaptive Reminder Engine and Dialogue Engine compute pacing, catch-up volumes, and mascot dialogue from live intake data.

Data layer — Room SQLite for entries and history, Jetpack DataStore for preferences, and a thin client for the Open-Meteo weather API.

System integration — custom notification RemoteViews, broadcast receivers for reminders and quick-drink actions, and a Glance home screen widget.

🧪 Testing & build

JUnit 4 suite covering the reminder pacing logic with mockable timestamp engines (30/30 passing). Min SDK 26 (Android 8.0), target SDK 35 (Android 15), Kotlin 2.0.20, signed with APK Signature Scheme v2.
